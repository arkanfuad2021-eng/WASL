# WASL (وَصْل) – Secure SMS Messaging Application

تطبيق **WASL (وَصْل)** هو نظام مراسلة نصية لامركزي فائق الخصوصية لأجهزة **Android**، يتيح للمستخدمين إرسال واستقبال رسائل مشفرة طرفاً لطرف (**End-to-End Encrypted**) عبر شبكة الاتصالات الخلوية التقليدية (**SMS**) دون أي اتصال بالإنترنت أو الاعتماد على خوادم وسيطة.

---

## 🔒 المبادئ الأمنية المعتمدة
- **صفر إنترنت**: لا توجد صلاحية `INTERNET` في ملف الـ Manifest، مما يضمن استحالة تسريب البيانات خارج الهاتف.
- **تطبيق مستقل**: يعمل بالتوازي مع تطبيق رسائل النظام الرسمي، دون أن يكون التطبيق الافتراضي.
- **حماية الرسائل في النظام**: يحتفظ تطبيق الرسائل الرسمي بالنص المشفر، بينما تُعرض وتُفك الرسائل داخل WASL فقط.
- **خوارزميات التشفير**:
  - **X25519**: لتبادل المفاتيح غير المتزامن واشتقاق السر المشترك.
  - **Ed25519**: للتوقيعات الرقمية وإثبات هوية المرسل ومنع التزوير.
  - **HKDF-SHA256**: لاشتقاق مفاتيح اتجاهية مستقلة ($K_{A \to B}$ و $K_{B \to A}$).
  - **AES-256-GCM**: لتشفير الرسائل والمصادقة على الرأس عبر AAD.
  - **Monotonic Nonce**: منع تكرار الـ Nonce نهائياً عبر عداد تسلسلي دائم + طابع زمني + أرقام عشوائية.
  - **SQLCipher**: تشفير قاعدة بيانات المحادثات والرسائل محلياً.

---

## 📱 مميزات التطبيق
- خطوط ثمانية الرسمية مدمجة (`thmanyah_black` للعناوين و `thmanyah_medium` للنصوص).
- دعم الوضعين الليلي والنهاري عالي التباين (Dark & Light Theme) مع زر تبديل فوري.
- دعم تعدد شرائح الاتصال (Dual-SIM) مع ميزة الضغط المطول على زر الإرسال لتحديد وتثبيت شريحة المحادثة.
- تجزئة الرسائل الطويلة وإعادة تجميعها بدقة حتى لو وصلت بترتيب مبعثر عبر أبراج الاتصالات.
- حساب لحظي لعدد أجزاء رسائل الـ SMS الفعلية بعد التشفير لحماية رصيد الشريحة.
- علامات حالة الرسائل (صح واحدة = نجاح الخروج من الهاتف، صحان = استلام تقرير التسليم الخلوي).
- مهلة 3 دقائق مع عداد تنازلي حي عند رفض طلب التأسيس، مع توليد معرّف جديد كلياً.
